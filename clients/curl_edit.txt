# 可选蒙版（透明区域为编辑区，尺寸需与首张 image 一致）:
# -F "mask=@mask.png;type=image/png"
# 继续加图时重复 image 字段即可（最多 16 张）:
# -F "image=@ref3.png;type=image/png"

字段说明：
image              输入图（必填），multipart 文件；gpt 支持 png/webp/jpg，单张 <50MB，最多 16 张
prompt             编辑提示词
mask               可选蒙版 PNG，透明区为编辑区域；多图时仅作用于第一张，尺寸需一致
model              模型名，如 gpt-image-2
n                  生成张数，通常 1（1-3）
size               输出分辨率，如 1024x1024 / 1536x1024 / 1024x1536 / auto；gpt-image-2 也可传合法 宽x高
quality            质量：low / medium / high / auto
background         背景：auto / opaque / transparent（gpt-image-2 不支持透明）
output_format      图片格式：png / jpeg / webp
output_compression 压缩质量 0-100，主要对 jpeg/webp 生效
partial_images     流式预览图数量 0-3，非流式填 0
stream             是否流式返回，建议 false
response_format    返回形式：固定为b64_json
user               终端用户标识，测试可随意填
