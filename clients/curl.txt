curl -X POST "http://st1.gpttap.top/v1/images/generations" \
  -H "Authorization: Bearer sk-qFC1tn5gRR1XgNf89kvbDVyyiht37bng163vppq2Un4TSgig" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "以雪为题，帮我生成一张照片",
    "n": 1,
    "size": "1024x1024",
    "quality": "high",
    "background": "auto",
    "moderation": "auto",
    "output_format": "png",
    "output_compression": 100,
    "partial_images": 0,
    "stream": false,
    "response_format": "b64_json",
    "user": "curl-test"
  }'

字段说明：
model              模型名，如 gpt-image-2
prompt             生图提示词
n                  生成张数，通常 1
size               分辨率，格式 宽x高，如 1024x1024
quality            质量：low / medium / high / auto
background         背景：auto / opaque / transparent（gpt-image-2 不支持透明）
moderation         审核强度：auto / low
output_format      图片格式：png / jpeg / webp
output_compression 压缩质量 0-100，主要对 jpeg/webp 生效
partial_images     流式预览图数量 0-3，非流式填 0
stream             是否流式返回，建议为false，流式不支持自定义大小
response_format    返回形式：固定为b64_json
user               终端用户标识，便于追踪，测试可随意填
